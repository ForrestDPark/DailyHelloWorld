av4 다운로드 파일원하는 파일을 선택하세요
Safari 다운로드가 보이지 않을 때
  1. Safari 화면에서 실제 진행률을 보려면 iPhone 설정 → 앱 → 기본 앱 → 브라우저 앱에서 Safari를 선택한 뒤 Safari에서 받기를 누르세요. 웹앱은 iOS의 기본 브라우저를 강제로 바꿀 수 없습니다.
  2. 저장되는 파일명은 원래 이름이 아니라 각 파일 카드에 적힌 "Files 앱 저장명"(짧은 작품 코드)입니다.
  3. Safari가 열리면 주소창 옆 ↓ 다운로드 아이콘을 누르세요. 진행 중에는 원형 진행 상태가 보이고, 완료 항목을 누르면 파일을 바로 확인할 수 있습니다.
  4. 나중에 찾을 땐 파일 앱에서 둘러보기 → iCloud Drive → Downloads를 먼저 확인하고, Safari 설정의 다운로드 위치가 "나의 iPhone"이면 나의 iPhone → Downloads를 확인하세요.
  5. 영상을 길게 눌러 이동 → 나의 iPhone → nPlayer → 루틴을 선택합니다.

다운로드 중 Safari를 닫거나 다른 앱으로 오래 전환하면 iOS가 전송을 중단할 수 있습니다. AirDrop은 Mac과 iPhone 양쪽에서 마지막 대상 선택·수락이 필요합니다.

DRM·유료 보호 영상은 지원하지 않으며 한 파일은 최대 5GB입니다.
