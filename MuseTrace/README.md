# Muse Trace

맥북 내장 웹캠으로 작품 감상 시선을 추정하고, 히트맵과 기초 관찰 지표를 만드는 로컬 우선 MVP입니다.

## 공개 사이트

[Muse Trace 바로 사용하기](https://muse-trace-eye-lab.pulpilisory.chatgpt.site)

맥북·데스크톱뿐 아니라 스마트폰의 전면 카메라도 지원합니다. 브라우저에서 카메라 권한을 허용한 뒤 얼굴을 안내선에 맞추고 보정을 진행하세요.

## 주요 기능

- 로컬 작품 이미지 업로드
- WebGazer 기반 웹캠 시선 추정
- 9점 × 5회 보정
- 15초 자유 감상 기록
- 선호·흥미·의도 명확성 설문
- 히트맵, 최초 포착 위치, 시선 중심 영역 리포트
- 표본이 적어도 확인할 수 있는 잠정 분석과 측정 품질 안내
- 데스크톱·모바일 반응형 화면 및 전면 카메라 지원
- 얼굴 영상과 작품 이미지를 서버에 저장하지 않는 브라우저 내 처리

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

Chrome에서 `http://localhost:3000`을 열고 카메라 권한을 허용하세요. 밝은 장소에서 화면과 약 50–70cm 거리를 유지하는 것이 좋습니다.

## 측정 품질 안내

`측정 품질이 낮습니다`는 분석을 할 수 없다는 뜻이 아니라, 유효한 시선 표본의 비율이 낮아 결과의 불확실성이 크다는 뜻입니다. 기기를 고정하고 얼굴 전체가 보이도록 조명을 밝게 한 뒤 다시 보정하면 개선될 수 있습니다. 표본이 적을 때도 결과는 잠정 분석으로 표시합니다.

## 개인정보

카메라 영상과 업로드한 작품은 브라우저 안에서 처리되며 서버에 저장하지 않습니다. 실제 관람자 연구에 사용할 때는 참여자의 동의를 별도로 받아야 합니다.

웹캠 기반 추정은 연구용 전용 아이트래커를 대체하지 않습니다. 작은 요소나 동공 반응보다 작품의 큰 영역 간 시선 경향을 탐색하는 용도로 사용하세요.
