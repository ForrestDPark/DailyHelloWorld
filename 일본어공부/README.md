# 일본어 구절 공부 파이프라인

이 문서는 `일본어자막추출` 파이프라인이 영상에서 수집한 일본어 대사를 바탕으로, Codex가 새 세션에서도 같은 형식의 일본어 공부 자료를 만들 수 있도록 정한 작업 명세다. 기본 골격은 `손자병법/README.md`의 구절 해석 파이프라인을 따르되, 고전 주석과 역사 사례 대신 실제 일본어의 문법·말투·발음·사용 상황을 깊게 분석한다.

> 이 문서가 일본어 공부 작업의 기준 문서다. 새 세션에서는 기억이나 이전 대화보다 이 README와 Notion의 최신 원문을 우선한다.

---

## 0. 시작 명령과 기본 원칙

### 사용자가 이렇게 말하면 시작한다

- `일본어 공부 README 읽고 시작해`
- `<작품명> 일본어 공부 시작해`
- `<일본어 구절> 해석해`
- `지난번 다음 구절 공부해`

### 기본 처리 단위

- 기본값은 **한 번에 구절 하나**다.
- 사용자가 `다음 5구절`처럼 개수를 지정한 경우에만 여러 구절을 처리한다.
- 너무 짧은 감탄사만 단독으로 고르지 않는다. 문법이나 말투를 배울 만한 완결된 발화 한 덩어리를 고른다.
- 한 자막이 문장 중간에서 끊겼다면 앞뒤 자막을 확인해 자연스러운 한 구절로 복원한다.
- Whisper 오인식이 의심되면 영상 시점과 앞뒤 문맥을 확인한다. 확신할 수 없는 부분은 원문을 임의로 확정하지 않고 `청취 불확실`로 표시한다.
- 성인용 영상에서 추출된 대사라도 학습 목적에 맞게 언어를 분석하되, 등장인물의 개인정보를 추정하거나 불필요하게 자극적인 묘사를 덧붙이지 않는다.

### 새 Codex 세션의 필수 작업 순서

1. 이 README를 끝까지 읽는다.
2. `일본어자막추출/README.md`에서 현재 추출·Notion 연동 방식을 확인한다.
3. 대상 작품의 Notion 페이지와 로컬 `일본어자막추출/library/<작품명>/` 자료를 읽는다.
4. Notion의 완료 기록을 확인해 아직 공부하지 않은 다음 구절을 고른다.
5. 원문과 타임코드를 영상·SRT·JSONL로 교차 확인한다.
6. 아래 7섹션 형식으로 초안을 작성하고 품질 검수를 한다.
7. Notion 학습 페이지에 저장한다.
8. 저장된 페이지를 다시 읽어 섹션 누락, 표기 오류, 중복 생성 여부를 확인한다.
9. 이 README의 완료 기록에 작품명·타임코드·구절·Notion 링크를 추가한다.

이 파이프라인은 현재 **수동 트리거 방식**이다. 사용자가 Codex 세션에서 실행을 요청해야 작업한다. 예약 실행이나 자동 다음 구절 해석은 별도 자동화를 만들기 전에는 존재하지 않는다.

## 1. 원본 자료와 우선순위

### Notion 원본 데이터베이스

- 일본어 자막 추출 DB:
  `https://app.notion.com/p/pulpilisory/35f32a1eae808058a38af59076445e42?v=35f32a1eae808042a715000c8a55a1a4&source=copy_link`
- 추출 파이프라인이 작품/파트별 페이지를 만들고 원문, 번역, 대표 이미지, Git 경로를 기록한다.
- Notion에 사용자가 직접 수정한 원문이나 메모가 있으면 자동 추출본보다 그 최신 수정 내용을 우선한다.

### 로컬 원본

```text
일본어자막추출/library/<작품명>/
  images/
  transcript_part1.jsonl
  transcript_part1.md
  notion_part1.json
  SUMMARY.md
```

### 원문 확인 우선순위

1. 사용자가 Notion에서 직접 교정한 일본어
2. 실제 영상 음성 및 해당 타임코드
3. `transcript_part*.jsonl`
4. `transcript_part*.md`
5. Whisper가 만든 SRT
6. 자동 한국어 번역

자동 번역문은 정답 원본이 아니라 참고 자료다. 해석 과정에서 일본어 원문을 기준으로 다시 번역한다.

## 2. 추천 Notion 구조

원본 추출 DB에 긴 학습 분석까지 모두 넣으면 작품·파트 정보와 공부 진도가 섞인다. 따라서 다음처럼 **원본 DB와 학습 DB를 분리**하는 방식을 권장한다.

### A. 기존 `일본어 자막 추출` DB

영상에서 자동 생성되는 원천 자료를 보관한다. 원문, 자동 번역, 대표 이미지, 작품 요약, Git 경로를 유지하며 학습 분석 때문에 원문을 덮어쓰지 않는다.

### B. 새 `일본어 구절 공부` DB

구절 하나당 페이지 하나를 만든다. 권장 속성은 다음과 같다.

| 속성 | 형식 | 용도 |
|---|---|---|
| 구절 | 제목 | 교정된 일본어 원문 |
| 작품 | 텍스트 또는 관계형 | 출처 작품 |
| 원본 페이지 | URL 또는 관계형 | 자막 추출 Notion 페이지 |
| 파트 | 숫자 | 원본 파트 번호 |
| 타임코드 | 텍스트 | `01:23:45.20` 형식 |
| 난이도 | 선택 | 초급 / 중급 / 고급 |
| JLPT 참고 | 선택 | N5 / N4 / N3 / N2 / N1 / 해당 없음 |
| 말투 | 다중 선택 | 정중체 / 보통체 / 반말 / 여성어 / 남성어 / 방언 등 |
| 학습 상태 | 선택 | 대기 / 분석 중 / 복습 대기 / 완료 |
| 복습 횟수 | 숫자 | 회상 학습 누적 횟수 |
| 다음 복습일 | 날짜 | 간격 반복 학습용 |
| 원문 신뢰도 | 선택 | 확인 / 청취 불확실 / 교정 필요 |

가능하면 `작품`은 기존 DB와의 관계형 속성으로 연결한다. 관계형 구성이 어렵다면 처음에는 `원본 페이지` URL과 `작품` 텍스트만 사용해도 된다.

### 중복 방지 키

`작품명 + 파트 + 시작 타임코드 + 원문`을 한 구절의 고유 식별자로 사용한다. 새 페이지를 만들기 전에 동일 키가 이미 있는지 검색한다.

## 3. 구절 선정 규칙

다음 순서로 학습 가치가 높은 구절을 우선한다.

1. 일상 회화에서 다시 사용할 수 있는 자연스러운 표현
2. 문법 구조나 조사 선택을 배울 수 있는 문장
3. 직역과 실제 의미가 다른 문장
4. 화자 관계에 따라 말투의 의미가 달라지는 문장
5. 축약·생략·연음 때문에 듣기 어려운 문장
6. 한자어의 일본어식 의미가 한국어 한자어와 다른 문장

다음 항목은 우선순위를 낮춘다.

- 이름을 부르는 말만 있는 자막
- 의미 없는 신음·감탄사
- Whisper 오인식이 심해 복구할 근거가 없는 문장
- 앞에서 이미 동일하게 분석한 반복 구절

사용자가 특정 구절을 지정하면 위 우선순위보다 사용자 지정을 우선한다.

## 4. 7섹션 해석 형식

### 1) 원문·독음·번역

- **원문:** 영상과 문맥을 확인해 교정한 일본어
- **독음:** 한자가 포함된 문장 전체를 히라가나로 표기
- **로마자:** 발음 확인이 실제로 도움이 될 때만 표기
- **직역:** 일본어 문장 구조가 보이도록 어순을 최대한 보존
- **자연스러운 번역:** 해당 장면과 화자 관계에 맞는 한국어
- **타임코드:** 원본 영상에서 다시 들을 수 있는 시작~종료 시각

자동 번역을 그대로 옮기지 않는다. 직역과 자연스러운 번역이 같다면 억지로 차이를 만들 필요는 없다.

### 2) 어휘·한자 뜻풀이

핵심 어휘만 표로 정리한다.

| 표현 | 독음 | 기본 뜻 | 이 구절에서의 뜻·뉘앙스 |
|---|---|---|---|
| 예시 | よみ | 사전적 의미 | 장면에서 실제로 전달하는 의미 |

- 한자는 가능하면 `훈독/음독`, 핵심 의미, 단어 안에서의 역할을 설명한다.
- 부수나 자형 설명은 기억에 실제로 도움이 될 때만 넣는다.
- 한국어의 같은 한자어와 의미가 다르면 반드시 차이를 짚는다.
- 너무 쉬운 조사와 기초 단어까지 개수를 채우려고 나열하지 않는다.
- 사전 뜻만 복사하지 말고 반드시 **이 구절에서 왜 이 단어를 썼는지** 설명한다.

### 3) 문법과 문장 구조

- 문장을 의미 덩어리로 끊어 구조를 보여준다.
- 활용형의 사전형과 변화 과정을 적는다.
- 생략된 주어·목적어·조사를 문맥에 근거해 설명한다.
- 핵심 문형은 `형태 → 기본 의미 → 이 장면의 기능` 순서로 설명한다.
- JLPT 등급은 공인된 절대 판정처럼 쓰지 말고 학습 난이도의 참고치로만 표시한다.

예시:

```text
言わなくてもいい
言う → 言わない → 言わなくて → 言わなくてもいい
말하지 않다 → 말하지 않아도 → 말하지 않아도 된다
```

### 4) 말투·관계·상황 뉘앙스

- 정중체/보통체, 거리감, 친밀도, 강압성, 완곡함을 분석한다.
- 종조사, 축약, 어미 선택이 화자의 감정과 관계를 어떻게 드러내는지 설명한다.
- 같은 문장도 누가 누구에게 말하느냐에 따라 달라지는 의미를 적는다.
- 여성어·남성어로 단정하기보다 실제 사용 경향과 개인차를 구분한다.
- 작품 속 표현이 현실에서 거칠거나 부자연스러울 수 있으면 분명히 표시한다.

### 5) 실제 발음과 듣기 포인트

- 음성에서 약해지거나 탈락한 소리, 연음, 장음, 촉음, 무성화를 짚는다.
- 표준적인 낭독과 실제 화자의 발음 차이를 설명한다.
- 확실히 들리지 않은 부분은 추측을 사실처럼 쓰지 않는다.
- 일본어 음성학 지식이나 사전 확인 없이 억양 핵을 숫자로 단정하지 않는다. 확인 가능한 경우에만 도쿄식 악센트를 보조 정보로 적는다.
- 원본 타임코드를 2~3회 듣고 따라 할 짧은 **섀도잉 단위**를 제시한다.

### 6) 바꿔 말하기와 실제 사용

아래 세 가지를 기본으로 제시한다.

1. **더 정중하게**
2. **일상적으로 자연스럽게**
3. **비슷하지만 뉘앙스가 다른 표현**

각 표현은 원문과 무엇이 달라지는지 한 줄로 설명한다. 문법적으로 가능해도 일본인이 실제로 잘 쓰지 않는 문장은 예문으로 만들지 않는다.

필요하면 상대방이 이 말을 했을 때 자연스럽게 이어질 **짧은 응답 예시**도 하나 추가한다.

### 7) 기억·복습 카드

- **한 줄 핵심:** 이 구절에서 반드시 기억할 표현 한 가지
- **빈칸 문제:** 핵심 문형이나 어휘 한 곳을 가린 문제
- **한국어 → 일본어:** 장면의 의미를 보고 원문을 떠올리는 문제
- **뉘앙스 질문:** 왜 다른 표현이 아니라 이 말투를 썼는지 묻는 문제
- **정답:** 토글 안에 넣어 먼저 보이지 않게 한다.
- **다음 복습 권장:** 1일 → 3일 → 7일 → 14일 → 30일

## 5. Notion 페이지 출력 구조

페이지 제목은 원문 전체가 너무 길지 않으면 원문을 그대로 쓰고, 길면 핵심 구절 뒤에 `…`를 붙인다.

페이지 최상단에는 다음 요약을 둔다.

```text
🎬 작품명 · Part 1 · 01:23:45.20
핵심 표현: ～なくてもいい
자연스러운 뜻: 말하지 않아도 돼
```

그 아래에 7개 섹션을 각각 토글로 만든다.

1. 원문·독음·번역
2. 어휘·한자 뜻풀이
3. 문법과 문장 구조
4. 말투·관계·상황 뉘앙스
5. 실제 발음과 듣기 포인트
6. 바꿔 말하기와 실제 사용
7. 기억·복습 카드

대표 이미지가 있다면 최상단 요약 아래에 해당 타임코드와 가장 가까운 장면 이미지 **한 장만** 둔다. 이미지가 정확한 장면과 대응하지 않으면 억지로 넣지 않는다.

원본 추출 페이지의 사용자 메모와 기존 블록은 삭제하거나 덮어쓰지 않는다. 학습 결과는 새 학습 페이지에 저장하고 원본 페이지에는 학습 페이지 관계 또는 링크만 추가한다.

## 6. 품질 검수

Notion에 저장하기 전 다음을 모두 확인한다.

- [ ] 원문을 앞뒤 문맥과 타임코드로 확인했는가
- [ ] 청취가 불확실한 부분을 임의로 확정하지 않았는가
- [ ] 히라가나 독음이 원문의 실제 활용형과 일치하는가
- [ ] 직역과 자연스러운 번역이 구분되는가
- [ ] 한자 풀이가 이 문맥의 의미로 연결되는가
- [ ] 동사·형용사 활용 과정에 오류가 없는가
- [ ] 말투와 화자 관계를 고정관념으로 단정하지 않았는가
- [ ] 실제로 쓸 수 있는 대체 표현과 복습 문제가 있는가
- [ ] 같은 구절의 학습 페이지가 이미 존재하지 않는가

저장 후 페이지를 다시 읽어 7개 섹션, 타임코드, 원본 연결, 이미지 위치, 토글 내부 정답이 정상인지 확인한다. 검수가 끝나기 전에는 `학습 상태=완료`로 바꾸지 않는다.

## 7. Codex용 실행 프롬프트

새 세션에서 아래처럼 요청하면 된다.

```text
일본어공부/README.md를 끝까지 읽고 일본어 구절 공부 파이프라인을 실행해.
Notion의 일본어 자막 추출 DB에서 <작품명>의 아직 공부하지 않은 다음 구절 하나를 골라,
원문과 타임코드를 확인한 뒤 7섹션 형식으로 분석해.
Notion에 저장하고 다시 검수한 다음 README 완료 기록도 갱신해.
```

특정 구절을 지정할 때:

```text
일본어공부/README.md 기준으로 아래 구절을 해석해:
「ここに 일본어 원문」
작품: <작품명>
타임코드: <시작~종료>
```

## 9. 향후 자동화 권장 순서

1. Notion에 `일본어 구절 공부` DB 생성 및 기존 추출 DB와 관계형 연결
2. `transcript_part*.jsonl`에서 학습 후보를 골라 `학습 상태=대기`로 등록하는 스크립트
3. Codex가 다음 미완료 구절을 찾아 7섹션 초안을 만드는 명령
4. 저장 전·후 7섹션과 중복 키를 검사하는 검증 스크립트
5. 복습일이 된 구절만 모아 퀴즈 페이지를 만드는 간격 반복 기능

처음부터 전 과정을 무인 자동화하지 않는다. 원문 청취 교정과 뉘앙스 검수가 안정된 뒤 후보 등록 → 분석 → 복습 순서로 단계적으로 자동화한다.
