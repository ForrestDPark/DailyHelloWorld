# 일본어 페이지 공부 파이프라인

이 문서는 `일본어자막추출` 파이프라인이 만든 작품별 Notion 원문을 바탕으로, Codex가 한 파트의 전체 상황을 먼저 파악한 뒤 학습 가치가 높은 대화와 어려운 표현만 골라 분석하도록 정한 작업 명세다. 기본 골격은 `손자병법/README.md`의 구절 해석 방식을 참고하지만, 모든 대사를 한 줄씩 해설하지 않는다.

> 새 세션에서는 이전 대화나 기억보다 이 README와 Notion의 최신 원문을 우선한다.

---

## 0. 시작 명령과 기본 원칙

### 사용자가 이렇게 말하면 시작한다

- `<작품명> [제 N편] 분석작업 시작해`
- `일본어 공부 README 읽고 시작해`
- `지난번 다음 편 공부해`

### 기본 처리 단위

- 기본값은 **Notion 원문 페이지 한 편 전체당 분석 페이지 하나**다.
- 먼저 전체 대사와 상황 흐름을 스캔한 뒤 핵심 대화 5~12개만 고른다.
- 쉬운 문장까지 한 구절씩 별도 페이지로 만들지 않는다.
- 반복되는 문법, 어려운 어휘·속어·축약, 듣기 어려운 발음은 페이지 단위로 묶어 설명한다.
- 한 자막이 문장 중간에서 끊겼다면 앞뒤 자막을 확인해 자연스럽게 복원한다.
- Whisper 오인식이 의심되면 타임코드와 문맥을 확인하고, 확신할 수 없는 부분은 `청취 불확실`로 표시한다.
- 성인용 영상에서 추출된 대사도 언어 학습에 필요한 범위에서만 다루며 인물의 개인정보를 추정하거나 자극적인 묘사를 덧붙이지 않는다.

### 새 Codex 세션의 필수 작업 순서

1. 이 README를 끝까지 읽는다.
2. `일본어자막추출/README.md`에서 최신 추출·Notion 연동 방식을 확인한다.
3. 대상 편의 Notion 원문과 `일본어자막추출/library/<작품명>/transcript_part*.jsonl`을 모두 읽는다.
4. 한 편의 등장 상황, 대화 흐름, 관계 변화를 먼저 정리한다.
5. 학습 가치가 높은 핵심 대화 5~12개와 어려운 표현을 선별한다.
6. 아래 페이지 단위 7섹션 형식으로 분석한다.
7. 원문 페이지의 자식 페이지로 분석 페이지 하나를 만들거나 기존 페이지를 갱신한다.
8. **원문 페이지 최상단에 분석 페이지 링크를 고정**한다.
9. 저장 결과를 다시 읽어 누락·중복·표기 오류와 이미지 위치를 검수한다.
10. 이 README의 완료 기록에 작품명·파트·범위·Notion 링크를 추가한다.

이 파이프라인은 사용자가 Codex 세션에서 요청할 때 실행하는 수동 트리거 방식이다.

- 사용자가 Notion에서 직접 수정한 원문이나 메모가 있으면 자동 추출본보다 우선한다.

### 로컬 원본

```text
일본어자막추출/library/<작품명>/
  images/
  transcript_part1.jsonl
  transcript_part1.md
  notion_part1.json
```

### 원문 확인 우선순위

2. 실제 영상 음성과 해당 타임코드
3. `transcript_part*.jsonl`
4. `transcript_part*.md`
5. Whisper SRT
6. 자동 한국어 번역

자동 번역은 참고 자료일 뿐이며 일본어 원문과 전체 문맥을 기준으로 다시 해석한다.

## 2. Notion 저장 구조와 중복 방지

- 원본 추출 페이지의 사용자 메모와 대사 블록을 삭제하거나 덮어쓰지 않는다.
- 분석 결과는 원본 페이지 아래의 자식 페이지 하나에 저장한다.
- 제목 형식: `<작품명> 제N편 핵심 대화·표현 분석`
- 원본 페이지 첫머리에 `📚 제N편 전체 핵심 분석` 링크를 두어 바로 열 수 있게 한다.
- 대표 이미지는 원본 페이지 상단에 큼직한 Notion 이미지 블록으로 둔다. 외부 임시 URL 대신 Notion File Upload API로 직접 저장한다.
- 중복 방지 키는 `작품명 + 파트`다. 같은 키의 분석 페이지가 있으면 새로 만들지 말고 갱신한다.

별도의 학습 데이터베이스가 꼭 필요한 것은 아니다. 복습 상태나 간격 반복 기능을 추가할 때만 기존 원문 DB와 관계형으로 연결된 학습 DB를 만든다.

## 3. 핵심 대화 선정 규칙

전체 페이지를 읽은 뒤 다음 순서로 5~12개를 고른다.

1. 장면의 상황이나 관계 변화를 이해하는 데 중요한 대화
2. 일상 회화에서 다시 쓸 수 있는 자연스러운 표현
3. 문법 구조나 조사 선택을 배울 수 있는 문장
4. 직역과 실제 의미가 다른 문장
5. 축약·생략·연음 때문에 듣기 어려운 문장
6. 한국어 한자어와 의미가 다른 일본어 한자어

이름 호출, 단순 감탄사, 의미 없는 반복, 복구 근거가 없는 오인식은 제외한다. 같은 표현이 반복되면 대표 예문 하나만 자세히 들고 나머지는 반복 표현으로 묶는다.

## 4. 페이지 단위 7섹션 분석 형식

### 1) 전체 상황과 대화 흐름

- 이 편에서 누가 어떤 상황에 있으며 대화가 어떻게 변하는지 짧게 요약한다.
- 장면을 과도하게 세분하지 말고 학습자가 문맥을 잡는 데 필요한 내용만 쓴다.

### 2) 핵심 대화 5~12개

각 항목에 다음만 간결하게 정리한다.

- 타임코드
- 교정된 일본어 원문. 문맥상 확실하고 일반적으로 한자로 쓰는 표현은 히라가나만 두지 말고 표준 한자로 복원한다.
- 모든 한자 바로 뒤에 `漢字(かんじ)` 형식으로 후리가나를 붙인 학습용 표기
- 문장 전체 독음이 필요하면 별도 히라가나 줄도 제공
- 자연스러운 번역
- 이 대사가 중요한 이유 또는 장면 속 뉘앙스

필요할 때만 직역을 덧붙인다. 쉬운 문장을 억지로 장문 해설하지 않는다.
동음이의어 때문에 표기를 확정할 수 없는 히라가나는 억지로 한자로 바꾸지 않고 `청취·표기 불확실`로 남긴다.

### 3) 반복 문법과 문장 구조

- 페이지에서 여러 번 나타나거나 실제 회화에 유용한 문형만 고른다.
- `형태 → 기본 의미 → 이 장면의 기능` 순서로 설명한다.
- 생략된 주어·목적어·조사는 전체 문맥에 근거해 설명한다.
- 활용 과정은 학습에 필요한 경우에만 제시한다.

### 4) 어려운 어휘·한자·속어·축약

| 표현 | 독음 | 기본 뜻 | 이 편에서의 뜻·뉘앙스 |
|---|---|---|---|
| 예시 | よみ | 사전적 의미 | 장면에서 실제로 전달하는 의미 |

- 쉬운 단어까지 개수를 채우려고 나열하지 않는다.
- 어려운 한자어는 구성 한자의 한국어 뜻, 단어 전체의 기본 뜻, 이 장면에서의 의미를 함께 적는다.
- 한자 뜻풀이는 기억에 도움이 되는 핵심 글자만 하되 한국인 학습자가 음과 뜻을 연결할 수 있게 한다.
- 속어, 구어 축약, 거친 표현, 한국어 한자어와 의미가 다른 단어를 우선한다.

### 5) 말투와 듣기 포인트

- 정중체/보통체, 거리감, 친밀도, 강압성, 완곡함을 전체 흐름 속에서 설명한다.
- 약화·탈락·연음·장음·촉음·무성화처럼 실제 청취에 영향을 주는 부분만 짚는다.
- 확실히 들리지 않은 부분을 추측으로 확정하지 않는다.
- 따라 듣기 좋은 짧은 섀도잉 표현을 3~5개 고른다.

### 6) Whisper 교정 후보

- 문맥상 오인식 가능성이 높은 원문, 현재 표기, 교정 후보, 판단 근거를 함께 기록한다.
- 음성을 확인하지 못했거나 후보가 여럿이면 `청취 불확실`로 남긴다.
- 확실한 근거 없이 원본 전체를 자동 교정하지 않는다.
- 음성·문맥 확인이 끝난 교정어만 `일본어자막추출/whisper_corrections.txt`에 한 줄씩 추가한다. 파이프라인은 다음 신규 영상의 Whisper 초기 프롬프트에 이 사전을 자동 포함한다.
- 초기 프롬프트는 모델 재학습이 아니라 고유명사·반복 어휘의 표기를 유도하는 기능이다. 기존 SRT 캐시에는 소급 적용되지 않는다.

### 7) 이 편에서 기억할 것

- 핵심 표현 5~10개
- 한국어 → 일본어 회상 문제 3~5개
- 장면의 말투나 뉘앙스를 묻는 질문 1~3개
- 필요하면 복습 권장일 `1일 → 3일 → 7일 → 14일 → 30일`

## 5. Notion 페이지 출력 순서

```text
🎬 작품명 · Part N · 시작~종료
한 줄 상황 요약

1. 전체 상황과 대화 흐름
2. 핵심 대화
3. 반복 문법과 문장 구조
4. 어려운 어휘·한자·속어·축약
5. 말투와 듣기 포인트
6. Whisper 교정 후보
7. 이 편에서 기억할 것
```

원문 페이지에서는 분석 링크가 항상 맨 위에 보여야 한다. 대표 이미지는 그 링크 바로 아래에 배치하고, 긴 대사 목록의 맨 아래에 몰아넣지 않는다.
