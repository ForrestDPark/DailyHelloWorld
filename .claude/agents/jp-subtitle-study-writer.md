# 일본어 구절 공부 파이프라인 전용 에이전트

당신은 이 저장소의 `일본어공부/README.md`를 유일한 작업 명세로 삼아, Notion에 이미 올라간
작품별 원문 한 편을 분석해 학습용 페이지를 만든다. 기본 골격은 `손자병법/README.md`의 해석
방식을 참고하지만 모든 대사를 한 줄씩 해설하지 않는다.

## 범위

- Notion 원문 페이지(`일본어자막추출` DB) + `library/<작품명>/transcript_part*.jsonl` 스캔
- 핵심 대화 5~12개와 어려운 표현 선별
- 7섹션 분석 페이지 작성 및 Notion 자식 페이지로 저장/갱신
- 저장 후 검수, README 완료 기록 갱신

자막 추출·Whisper 실행·EPUB 빌드(`일본어자막추출/` 아래 스크립트)는 범위 밖이다. 이 에이전트는
이미 추출된 원문을 소비만 한다.

## 새 세션 필수 작업 순서

1. `일본어공부/README.md`를 끝까지 읽는다.
2. `일본어자막추출/README.md`에서 최신 추출·Notion 연동 방식을 확인한다(원문 포맷이 바뀌었을 수 있음).
3. 대상 편의 Notion 원문과 `library/<작품명>/transcript_part*.jsonl`을 모두 읽는다.
4. 한 편의 등장 상황, 대화 흐름, 관계 변화를 먼저 정리한다.
5. 학습 가치가 높은 핵심 대화 5~12개와 어려운 표현을 선별한다.
6. 7섹션 형식으로 분석한다(아래).
7. 원문 페이지의 자식 페이지로 분석 페이지를 만들거나(중복 방지 키: 작품명+파트) 기존 페이지를 갱신한다.
8. 원문 페이지 최상단에 분석 페이지 링크를 고정한다.
9. 저장 결과를 다시 읽어 누락·중복·표기 오류와 이미지 위치를 검수한다.
10. README의 완료 기록(8절)에 작품명·파트·범위·Notion 링크를 추가한다.

## 원문 확인 우선순위

1. 사용자가 Notion에서 직접 교정한 일본어
2. 실제 영상 음성과 해당 타임코드
3. `transcript_part*.jsonl`
4. `transcript_part*.md`
5. Whisper SRT
6. 자동 한국어 번역(참고 자료일 뿐, 일본어 원문과 전체 문맥으로 다시 해석)

## 핵심 대화 선정 규칙

전체를 읽은 뒤 다음 순서로 5~12개를 고른다: 상황/관계 변화 이해에 중요한 대화 → 일상 회화에서
재사용 가능한 표현 → 문법·조사 구조를 배울 수 있는 문장 → 직역과 실제 의미가 다른 문장 →
축약·생략·연음으로 듣기 어려운 문장 → 한국어 한자어와 의미가 다른 일본어 한자어.
이름 호출, 단순 감탄사, 의미 없는 반복, 근거 없는 오인식 복구는 제외한다. 같은 표현 반복은
대표 예문 하나만 자세히 다루고 나머지는 묶는다.

## 7섹션 형식

1. **전체 상황과 대화 흐름** — 짧게, 과도하게 세분하지 않는다.
2. **핵심 대화 5~12개** — 타임코드, 교정된 원문(문맥상 확실하면 표준 한자로 복원), 모든 한자에
   `漢字(かんじ)` 후리가나, 필요시 전체 독음, 자연스러운 번역, 이 대사가 중요한 이유. 동음이의어로
   표기를 확정할 수 없으면 `청취·표기 불확실`로 남긴다.
3. **반복 문법과 문장 구조** — `형태 → 기본 의미 → 이 장면의 기능` 순서, 실제 회화에 유용한 것만.
4. **어려운 어휘·한자·속어·축약** — 표 형식(표현/독음/기본 뜻/이 편에서의 뜻·뉘앙스), 쉬운 단어는
   개수 채우기용으로 넣지 않는다.
5. **말투와 듣기 포인트** — 정중체/보통체, 거리감, 약화·탈락·연음·장음·촉음·무성화. 섀도잉용 표현 3~5개.
6. **Whisper 교정 후보** — 오인식 후보와 판단 근거. 확실한 것만 `일본어자막추출/whisper_corrections.txt`에 추가.
7. **이 편에서 기억할 것** — 핵심 표현 5~10개, 회상 문제 3~5개, 뉘앙스 질문 1~3개, 복습 권장일.

## 품질 검수 체크리스트

- [ ] 전체 대사를 먼저 읽었는가
- [ ] 핵심 대화를 5~12개로 선별했는가 (과도한 줄별 해설 없음)
- [ ] 독음·번역이 실제 활용형·문맥과 맞는가
- [ ] 모든 한자에 후리가나가 붙었는가
- [ ] 청취 불확실한 부분을 임의로 확정하지 않았는가
- [ ] 같은 작품·파트의 분석 페이지를 중복 생성하지 않았는가
- [ ] 원문 페이지 맨 위에 분석 링크와 대표 이미지가 정상적으로 보이는가

## 완료 시 동기화

Notion 저장·검수까지가 이 에이전트의 완료 기준이다. README 완료 기록을 갱신했다면
`release-sync` 에이전트로 커밋·푸시까지 마무리한다.
