# 실행 계획

이직시스템 `README.md`의 "7. 교대근무에 맞춘 실행 루틴"(피곤한 근무일 15분 / 보통 상태 45분 / 휴무일 2시간) 시간 배분을 그대로 적용한다. 목표는 완벽한 제품이 아니라 **자기소개서·면접에서 "문제 → 판단·구현 → 측정 가능한 결과"로 설명할 수 있는 증거**를 2~3주 안에 만드는 것이다.

## 마일스톤

### M1 — OCR 텍스트 추출 MVP
- [ ] 가짜 샘플 문서 5종(견적서·발주서·계약서·수입물류서류·영수증) 직접 제작(실제 회사 문서 절대 사용 금지)
- [ ] `pytesseract` + `pdf2image`로 PDF/이미지 → 텍스트 추출 함수 작성
- [ ] 한글 OCR 정확도 확인(언어팩 `kor`, 스캔 품질에 따른 오인식 샘플 기록)
- [ ] 파일 해시(sha256) 기준 캐시 — 같은 파일 재처리 생략
- **목표 소요**: 휴무일 2회
- **완료 기준**: 샘플 5종 전부 텍스트로 뽑히고, 같은 파일을 다시 넣으면 캐시로 즉시 스킵됨을 로그로 확인

### M2 — LLM 문서 분류·핵심 항목 추출
- [ ] 문서 종류 5종에 대한 분류·추출 프롬프트 설계(문서종류, 거래처, 금액, 날짜, 문서번호, 신뢰도 JSON 출력)
- [ ] 이직시스템 `ai_exec.py` 패턴 재사용해 API 실패 시 재시도·폴백 구현
- [ ] 추출 결과 캐시(같은 텍스트 재분석 방지)
- [ ] 잘못 분류/추출된 샘플에 대한 실패 케이스 기록(오류 유형별로 정리 — 면접에서 "어떻게 진단·개선했는가" 답변 재료)
- **목표 소요**: 휴무일 1회 + 보통 상태 2회
- **완료 기준**: 샘플 5종 각각의 문서종류·핵심 항목이 JSON으로 정확히 나오고, 오류 사례 최소 1건과 그 원인·개선 기록이 있음

### M3 — 표준 템플릿 자동 생성
- [ ] 문서종류별 마크다운/JSON 표준 템플릿 정의
- [ ] 추출된 항목을 템플릿에 채워 저장하는 `template_writer.py`
- **목표 소요**: 보통 상태 2회
- **완료 기준**: 5종 샘플 각각 표준 템플릿 파일이 생성됨

### M4 — SQLite 저장 + 검색
- [ ] `documents` 테이블(파일 해시, 원문 경로, 추출 텍스트, 문서종류, 거래처, 금액, 날짜, 템플릿 경로, 처리 시각)
- [ ] `retry_queue` 테이블(실패한 단계·문서·사유·재시도 횟수)
- [ ] 거래처/기간/문서종류 검색 CLI
- **목표 소요**: 휴무일 1회
- **완료 기준**: CLI로 "거래처명 포함 검색", "이번 달 문서만" 같은 조건 검색이 됨

### M5 — 검색 웹 화면
- [ ] Flask 최소 화면(검색창 + 결과 목록 + 템플릿 미리보기)
- [ ] 로컬 실행 스크린샷/짧은 시연 영상 확보(포트폴리오용)
- **목표 소요**: 휴무일 1회
- **완료 기준**: 브라우저에서 검색 → 결과 클릭 → 표준 템플릿 내용이 보임

### M6 — 테스트·문서화·마무리
- [ ] `test_ocr_pipeline.py` — 각 모듈 단위 테스트(이직시스템 컨벤션대로 목·픽스처 사용)
- [ ] 처리 시간 측정(문서 1건당 평균 처리 시간, "몇 분 걸리던 작업이 몇 초로 줄었다" 수치화)
- [ ] README.md의 "5. 사용 방법" 채우기, 구조도 추가
- [ ] 이직시스템 노션 페이지의 "4. 포트폴리오 시스템"에 후보 E로 등록
- **목표 소요**: 휴무일 1회 + 보통 상태 2회

## 프로젝트 페이지 작성 시 답할 질문 (이직시스템 컨벤션)

1. 어떤 불편이 있었는가 — 문서가 흩어져 못 찾고, 반복 문서작업에 시간을 씀
2. 누가 사용하는가 — 문서 처리 담당자(사무직 1인 체제인 소규모 제조업 등)
3. 어떤 방식으로 해결했는가 — OCR + LLM 분류·추출 + 표준 템플릿 + 검색
4. 전체 시스템 구조 — 위 아키텍처 다이어그램
5. 가장 어려웠던 문제 — (구현 중 기록)
6. 오류를 어떻게 진단하고 개선했는가 — M2의 실패 케이스 기록 활용
7. 처리 시간이나 반복 작업이 얼마나 줄었는가 — M6에서 수치화
8. 기술을 선택한 이유와 다른 대안 — 로컬 Tesseract vs 클라우드 OCR API 비교 기록
9. 다시 만든다면 바꾸고 싶은 부분
10. 실행 영상·GitHub·시연 링크
